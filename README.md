# Oxide TFT Research Repository

## Introduction

This repository contains research materials, simulation codes, experimental data analysis tools, and documentation related to oxide thin-film transistors (TFTs).

The primary focus is on high-performance crystalline and polycrystalline InGaO-based TFTs for next-generation display applications, including AMOLED, LTPO backplanes, micro-LED driving circuits, and oxide semiconductor memory devices.

This repository is used for device design, fabrication process optimization, electrical characterization, material analysis, and TCAD simulation studies.

## Main Features

- Oxide TFT device characterization
- Polycrystalline InGaO TFT research
- TCAD simulation and parameter extraction
- XRD, XPS, UPS, REELS, and PL data analysis
- TFT reliability evaluation (PBTS, NBTS, HCS)
- Display circuit applications
  - Ring Oscillator
  - Gate Shift Register
  - Micro-LED Pixel Circuits
- Research documentation and publication resources

## Research Topics

### Materials
- Amorphous InGaO (a-IGO)
- Polycrystalline InGaO (poly-IGO)
- Crystalline InGaO (c-IGO)
- Oxide semiconductor engineering

### Device Structures
- Self-aligned coplanar TFT
- Dual-gate TFT
- Active split-channel TFT
- High-mobility oxide TFT

### Applications
- AMOLED displays
- LTPO backplanes
- Micro-LED displays
- Oxide semiconductor memory
